# Upino website

Static site: `index.html`, `styles.css`, `main.js`. No build step; serve the folder.

- GSAP 3.12.5 (+ ScrollTrigger) loads from cdnjs for the pinned Safe-to-Spend sequence and chart morphs. Without it, or with reduced motion, every demo still works and shows its final state.
- All demo figures come from one model in `main.js`, so the numbers across sections agree. They are examples, labelled as such on the page.
- Placeholders to fill before launch: the domain (`upino.example` in `index.html`, `robots.txt`, `sitemap.xml`), store links, press/contact address, terms page.
